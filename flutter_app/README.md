# From Fridge to Fork

Flutter rebuild of the recipe app.

## Run

Web:

```bash
cd /Users/hadleyarcemont/Documents/GitHub/From-Fridge-to-Fork/flutter_app
~/development/flutter/bin/flutter run -d chrome
```

iOS Simulator:

```bash
cd /Users/hadleyarcemont/Documents/GitHub/From-Fridge-to-Fork/flutter_app
~/development/flutter/bin/flutter run -d <iOS simulator device id>
```

If the simulator is not listed yet, start it from Xcode or Simulator first, then rerun `flutter devices` to copy the exact id.
